Computers Follow Instructions Fast

The language we use to write instructions for websites is called HTML . It's made of tags — labels that tell the browser what to do with your content.

The Browser Reads Your Instructions

A browser is just reading your instructions and turning them into something visual. You're the one writing the instructions. That makes you the coder.

Key Terms
LESSON 01 · TAP TO EXPAND
Code ›
A set of step-by-step instructions written in a language a computer can understand. Example: Telling a browser "make this text a heading" is code.
HTML ›
HyperText Markup Language. The language used to build every webpage. Example: Every website you've visited was built with HTML.
Tag ›
A label in angle brackets that tells the browser what content is. Example: <h1>This is a heading</h1>
Browser ›
The program that reads HTML and turns it into a visual webpage. Example: Chrome, Safari, Firefox.

Element ›

Extra info inside an opening tag. Example: href sets a link's destination.

Key Terms
LESSON 03 · TAP TO EXPAND
CSS ›
Cascading Style Sheets. Example: color: pink;
Selector ›
Targets which element to style. Example: h1 {}
Property ›
What you want to change. Example: color, font-size.
Value ›
What you set the property to. Example: red is the value in color: red;
Hex Color ›
A six-character code representing an exact color. Example: #ff6baa is Zen's pink.

Zen's Cheat Sheet
ALL FOUR LESSONS · COMBINED REFERENCE

✦ Lesson 1 — What Is Code?

Code
Step-by-step instructions a computer can read and follow.
HTML
HyperText Markup Language — the language of web pages.
Tag
Labels in angle brackets that tell the browser what content is.
Browser
The program that reads HTML and displays it as a webpage.
<h1> Hello, I'm Zen. </h1>
<p> I build things with code. </p>

✦ Lesson 2 — Your First HTML Tag

Opening Tag
Starts an element. Written as <tagname>
Closing Tag
Ends an element. Written as </tagname>
Element
Opening tag + content + closing tag together.
Attribute
Extra info inside an opening tag, like href.
<a href = "https://..." > Click here </a>

✦ Lesson 3 — Colors & Style with CSS

CSS
The language that styles HTML — colors, fonts, spacing.
Selector
Targets which element to style. Example: h1 {}
Property
What to change: color, font-size, background.
Value
What to set it to: pink, 2rem, #ff6baa.
h1 {
   color : #ff6baa ;
   font-size : 2rem ;
}

✦ Lesson 4 — Build Your Own Page

<!DOCTYPE html>
Tells the browser this is an HTML5 document. Always goes first.
<head>
Settings section. Not visible. Holds title, styles, fonts.
<body>
Everything the visitor sees goes here.
<style>
Write CSS inside this tag, inside the head.
<!DOCTYPE html>
<html>
 <head><title>My Page</title></head>
 <body><h1>Hello!</h1><p>A paragraph.</p></body>
</html>

✦ Symbols Reference

<
Opening bracket. Starts every tag.
>
Closing bracket. Ends every tag.
</
Opening bracket + slash. Starts a closing tag — this is how a tag says "I'm done."
!
Exclamation point. Only used once, in <!DOCTYPE html>, to mark it as a special declaration rather than a normal tag.
{}
Curly braces. Wrap the style rules in CSS, right after a selector.
:
Colon. Separates a CSS property from its value, like color: pink;
;
Semicolon. Ends a CSS line, like a period ends a sentence.
#
Pound sign. Starts a hex color code, like #ff6baa.
