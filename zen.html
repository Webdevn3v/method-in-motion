What is Code?

Before you build anything, you need to understand what you're actually doing. Spoiler: it's simpler than you think.

"Hey, I'm Zen. I build things with code — websites, animations, digital art. Before I learned how, I had one question: what even IS this stuff?"

Code is just a set of instructions. That's it. When you tell your little sibling how to make a sandwich — get bread, add peanut butter, put it together — that's basically code. You're giving step-by-step instructions to make something happen.

Computers are the same. They follow instructions really, really fast. The language we use to write instructions for websites is called HTML. It's made of things called tags — labels that tell the browser what to do with your content.

A browser is just reading your instructions and turning them into something visual. You're the one writing the instructions. That makes you the coder.

📚
Key Terms
Code
A set of step-by-step instructions written in a language a computer can understand.
Example: Telling a browser "make this text a heading" is code.
HTML
HyperText Markup Language. The language used to build the structure of every webpage on the internet.
Example: Every website you've ever visited was built with HTML.
Tag
A label wrapped in angle brackets that tells the browser what a piece of content is. Tags come in pairs — an opening tag and a closing tag.
Example: <h1>This is a heading</h1>
Browser
The program that reads your HTML and turns it into a visual webpage. Chrome, Safari, and Firefox are all browsers.
Example: When you visit a website, your browser is reading code and showing it to you as a page.

Your First HTML Tag

Tags are the building blocks of every webpage. Learn how they work, what they look like, and write your first real HTML.

🔒
Sparks · Builders · Coders
This lesson is for members
Join the crew to unlock Lesson 2 and everything that comes after it. No experience needed — just bring your ideas.
📖
Read · 3 min

"Once I understood what a tag was, everything clicked. It's like putting a label on a box so the browser knows what's inside."

Every HTML tag follows the same pattern. An opening tag tells the browser where something starts. A closing tag (with a slash) tells it where it ends. Everything in between is the content.

Some tags are for structure — like headings and paragraphs. Some are for links. Some are for images. Each one has a job, and once you know a tag's job, you own it forever.

The most important thing to remember: browsers are forgiving. If you make a mistake, nothing breaks permanently. You just fix it and try again. That's what coders do.

📚
Key Terms
Opening Tag
The start of an HTML element. Written as the tag name inside angle brackets.
Example: <p> opens a paragraph.
Closing Tag
The end of an HTML element. Same as the opening tag but with a forward slash before the name.
Example: </p> closes a paragraph.
Element
The complete unit — opening tag, content, and closing tag together.
Example: <h1>My Title</h1> is one element.
Attribute
Extra information added inside an opening tag to modify how it works.
Example: <a href="https://..."> — href is the attribute that sets the link destination.
Anchor Tag (<a>)
The HTML tag that creates a clickable link. Uses the href attribute to set the destination.
Example: <a href="https://google.com">Click here</a>

Lesson 03 · Builders+

Colors & Style with CSS

HTML builds the structure. CSS makes it beautiful. Learn how to add color, fonts, and style to everything you build.

🔒
Builders · Coders
This lesson is for Builders and up
Upgrade your membership to unlock Lesson 3 — where your pages start to actually look like something.
📖
Read · 3 min

"HTML is the skeleton. CSS is everything that makes it look alive — the colors, the fonts, the spacing, all of it."

CSS stands for Cascading Style Sheets. It's a separate language from HTML, but the two work together. While HTML says "this is a heading," CSS says "make that heading pink and use this font."

CSS works by selecting an element and then telling it how to look. You write a selector (like h1), then inside curly braces you write properties and values — each one changing something about how that element appears.

The word "cascading" means styles flow down from parent to child. If you set a color on the body, everything inside inherits it unless you override it. This makes it powerful and efficient once you get the feel for it.

📚
Key Terms
CSS
Cascading Style Sheets. The language that controls how HTML elements look — colors, fonts, spacing, layout.
Example: color: pink; makes text pink.
Selector
The part of a CSS rule that targets which HTML element to style.
Example: h1 { } targets all h1 headings.
Property
What you want to change about an element — like color, font-size, or background.
Example: color is the property in color: red;
Value
What you set the property to.
Example: red is the value in color: red;
Hex Color
A six-character code starting with # that represents an exact color. Every color on a screen can be written as a hex code.
Example: #ff6baa is Zen's pink.

Build Your Own Page

Everything you've learned comes together here. You're going to build a real webpage from scratch — about something you actually care about.

🔒

Read · 2 min

"The first page I ever built was about my favorite song. It was simple. But it was MINE. I made it. That feeling never goes away."

Every real webpage on the internet starts with the same thing: an HTML file. Inside that file, there's a structure — a head section that holds settings, and a body section that holds everything you actually see.

In this lesson, you're going to build that structure, add your own content, and style it with CSS. By the time you're done, you'll have a complete webpage — something you actually built, from scratch, with your own hands.

There's no wrong way to do this. Pick a topic you care about. Use what you've learned. And remember — every single website you've ever visited started exactly like this.

📚
Key Terms
HTML Document
A complete HTML file that a browser can read and display as a webpage. It starts with <!DOCTYPE html> and contains head and body sections.
<head>
The section of an HTML document that contains settings and information about the page — like the title that shows in the browser tab. The head is not visible on the page itself.
Example: <title>My Page</title> goes inside the head.
<body>
The section of an HTML document that contains everything visible on the page — headings, paragraphs, links, images.
<style>
A tag that lets you write CSS directly inside your HTML file, inside the head section.
⚡
See It Live · Full Page Structure
