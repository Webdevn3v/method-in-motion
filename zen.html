What Is Code?
LESSON 01 · FREE
01 / 04

Instructions, Not Magic

"Hey, I'm Zen. I build things with code — websites, animations, digital art. Before I learned how, I had one question: what even IS this stuff?"

Code is just a set of instructions. That's it. When you tell your little sibling how to make a sandwich — get bread, add peanut butter, put it together — that's basically code. You're giving step-by-step instructions to make something happen.

02 / 04

Computers Follow Instructions Fast

Computers are the same as that sandwich example. They follow instructions really, really fast. The language we use to write instructions for websites is called HTML. It's made of things called tags — labels that tell the browser what to do with your content.

03 / 04

The Browser Reads Your Instructions

A browser is just reading your instructions and turning them into something visual. You're the one writing the instructions. That makes you the coder.

04 / 04

Every Website Started This Way

Every single website you've ever visited was built with HTML at its core. Instagram, YouTube, your school's homepage — all of it starts with the same basic tags you're about to learn.

Key Terms
LESSON 01 · TAP TO EXPAND
Code ›
A set of step-by-step instructions written in a language a computer can understand.Example: Telling a browser "make this text a heading" is code.
HTML ›
HyperText Markup Language. The language used to build the structure of every webpage on the internet.Example: Every website you've ever visited was built with HTML.
Tag ›
A label wrapped in angle brackets that tells the browser what a piece of content is. Tags come in pairs — an opening tag and a closing tag.Example: <h1>This is a heading</h1>
Browser ›
The program that reads your HTML and turns it into a visual webpage. Chrome, Safari, and Firefox are all browsers.Example: When you visit a website, your browser is reading code and showing it to you as a page.

Your First HTML Tag
LESSON 02 · SPARKS+
01 / 04

Labels for the Browser

"Once I understood what a tag was, everything clicked. It's like putting a label on a box so the browser knows what's inside."

Every HTML tag follows the same pattern. An opening tag tells the browser where something starts. A closing tag (with a slash) tells it where it ends. Everything in between is the content.

02 / 04

Every Tag Has a Job

Some tags are for structure — like headings and paragraphs. Some are for links. Some are for images. Each one has a job, and once you know a tag's job, you own it forever.

03 / 04

Mistakes Aren't Permanent

The most important thing to remember: browsers are forgiving. If you make a mistake, nothing breaks permanently. You just fix it and try again. That's what coders do.

04 / 04

Attributes Add Extra Info

Some tags take extra information called an attribute, written inside the opening tag. The most common one you'll use is href on a link, which tells the browser where the link should go.

<a href="https://...">Click here</a>
Key Terms
LESSON 02 · TAP TO EXPAND
Opening Tag ›
The start of an HTML element, written as the tag name inside angle brackets.Example: <p> opens a paragraph.
Closing Tag ›
The end of an HTML element — same as the opening tag but with a forward slash before the name.Example: </p> closes a paragraph.
Element ›
The complete unit — opening tag, content, and closing tag together.Example: <h1>My Title</h1> is one element.
Attribute ›
Extra information added inside an opening tag to modify how it works.Example: href sets a link's destination.
Anchor Tag (<a>) ›
The HTML tag that creates a clickable link. Uses the href attribute to set the destination.Example: <a href="https://google.com">Click here</a>

Colors & Style with CSS
LESSON 03 · BUILDERS+
01 / 04

The Skeleton and the Style

"HTML is the skeleton. CSS is everything that makes it look alive — the colors, the fonts, the spacing, all of it."

CSS stands for Cascading Style Sheets. It's a separate language from HTML, but the two work together. While HTML says "this is a heading," CSS says "make that heading pink and use this font."

02 / 04

Select, Then Style

CSS works by selecting an element and then telling it how to look. You write a selector (like h1), then inside curly braces you write properties and values — each one changing something about how that element appears.

h1 {
  color: #ff6baa;
}
03 / 04

Why It's Called "Cascading"

The word "cascading" means styles flow down from parent to child. If you set a color on the body, everything inside inherits it unless you override it. This makes it powerful and efficient once you get the feel for it.

04 / 04

Hex Colors

Colors in CSS are often written as a hex code — a six-character code starting with #. Every color you can imagine has a hex code, and once you learn a few you'll start recognizing them on sight.

Key Terms
LESSON 03 · TAP TO EXPAND
CSS ›
Cascading Style Sheets. The language that controls how HTML elements look — colors, fonts, spacing, layout.Example: color: pink; makes text pink.
Selector ›
The part of a CSS rule that targets which HTML element to style.Example: h1 { } targets all h1 headings.
Property ›
What you want to change about an element — like color, font-size, or background.Example: color is the property in color: red;
Value ›
What you set the property to.Example: red is the value in color: red;
Hex Color ›
A six-character code starting with # that represents an exact color.Example: #ff6baa is Zen's pink.

Build Your Own Page
LESSON 04 · CODERS
01 / 03

The First Page I Ever Built

"The first page I ever built was about my favorite song. It was simple. But it was MINE. I made it. That feeling never goes away."

Every real webpage on the internet starts with the same thing: an HTML file. Inside that file, there's a structure — a head section that holds settings, and a body section that holds everything you actually see.

02 / 03

Head vs. Body

The head holds information about the page — like its title — but nothing in the head is visible on the page itself. The body holds everything the visitor actually sees: headings, paragraphs, links, images.

03 / 03

No Wrong Way to Start

In this lesson, you're going to build that structure, add your own content, and style it with CSS. There's no wrong way to do this. Pick a topic you care about. Every single website you've ever visited started exactly like this.

Build It
LESSON 04 · FULL PAGE STRUCTURE

A Complete HTML Document

This is what a complete HTML document looks like. Every webpage you've ever visited has this skeleton underneath.

<!DOCTYPE html>
<html>
  <head>
    <title>My First Page</title>
  </head>
  <body>
    <h1>Welcome to My Page</h1>
  </body>
</html>
