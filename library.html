History of Coding

How we got from gears to generative AI.

A fast timeline through the ideas, languages, machines, and breakthroughs that made modern computing possible.

1843
Mathematics

Ada Lovelace Writes an Algorithm

Lovelace described a method for Charles Babbage’s Analytical Engine and recognized that machines might one day manipulate more than numbers.

1890
Data

Punch Cards Speed Up the Census

Herman Hollerith created machines that recorded and processed information using holes punched into cards.

1936
Theory

Alan Turing Defines a Computing Model

Turing described a theoretical machine that helped establish the mathematical foundation of computer science.

1940s
Hardware

Electronic Computers Arrive

Machines such as ENIAC used thousands of vacuum tubes and filled large rooms while performing calculations at unprecedented speed.

1957
Languages

FORTRAN Brings Code Closer to Mathematics

FORTRAN made it easier for scientists and engineers to write programs without manually entering machine instructions.

1969
Internet

ARPANET Sends Its First Message

A small network connected university computers and became an important ancestor of the modern internet.

1972
Languages

C Is Created at Bell Labs

Dennis Ritchie developed C while working on Unix. Its influence can still be seen across modern programming languages and operating systems.

1984
Personal Computing

Graphical Interfaces Reach More Homes

The Macintosh helped popularize windows, icons, menus, and mouse-based interaction for everyday computer users.

1989
Web

Tim Berners-Lee Proposes the World Wide Web

The web connected documents using links and made information easier to share across the internet.

1995
Languages

JavaScript Makes the Web Interactive

JavaScript began as a browser scripting language and later expanded to servers, mobile applications, tools, and devices.

2007
Mobile

The Smartphone Era Accelerates

Touchscreen smartphones combined communication, computing, cameras, and the web into one pocket-sized device.

2020s
AI

Generative AI Reaches Everyday Users

Tools that generate text, code, images, audio, and video become widely available, making strong computing fundamentals even more valuable.

History of the Internet

The network that connected everything.

The internet is the network. The web is one way of sharing linked information across it.

1969

ARPANET Connects Four Sites

Researchers connect computers at several universities.

1971

Network Email Appears

Ray Tomlinson sends messages between computers and uses the @ symbol.

1983

TCP/IP Becomes the Standard

Networks adopt shared communication rules central to the internet.

1989

The World Wide Web Is Proposed

Tim Berners-Lee proposes linked documents accessed over the internet.

1993

Graphical Browsers Spread

Browsers such as Mosaic make websites easier to navigate.

1998

Google Launches

A search engine uses links between pages as a ranking signal.

2000s

Social Platforms Grow

People increasingly create, share, comment, stream, and collaborate.

Today

The AI-Connected Web

Creation and software increasingly combine human input with machine-generated output.

Tech Pioneers

The people behind the breakthroughs.

Every system began with people asking questions, testing ideas, and building what did not exist yet.

1840s · Mathematics

Ada Lovelace

Early computing visionary

Described an algorithm for the Analytical Engine and imagined broader uses for computing machines.

1930s · Computer Science

Alan Turing

Foundational computer scientist

Developed influential ideas about computation and played a major role in wartime codebreaking.

1940s · Programming

Grace Hopper

Compiler pioneer

Helped create early compilers and promoted languages that were easier for humans to read.

Spaceflight · Mathematics

Katherine Johnson

NASA mathematician

Calculated flight paths and orbital trajectories for major space missions.

1970s · Personal Computing

Steve Wozniak

Computer engineer

Designed the Apple I and Apple II, helping make personal computers practical.

1989 · Web

Tim Berners-Lee

Inventor of the World Wide Web

Created the core ideas behind URLs, HTTP, HTML, and linked web pages.

1990s · Search

Larry Page & Sergey Brin

Google co-founders

Built a search system that used links between pages as a major ranking signal.

Modern AI · Research

Geoffrey Hinton

Neural-network researcher

Helped advance deep-learning methods used in modern artificial intelligence.

Your browser finds servers, downloads files, builds structures, and paints pixels.

02

The Browser Sends a Request

It connects to a server and asks for files or data.

03

The Server Responds

The server returns HTML, CSS, JavaScript, images, and resources.

04

HTML Builds the Structure

The browser reads HTML and creates the DOM.

05

CSS Styles the Page

CSS controls layout, spacing, colors, fonts, and animation.

06

JavaScript Adds Behavior

How computers store information

Text, pictures, sound, and video all become digital data.

BIT

The Smallest Unit

A bit is one binary digit: either 0 or 1.

BYTE

Eight Bits

A byte contains eight bits and can represent 256 values.

KB → TB

Scaling Up

Kilobytes, megabytes, gigabytes, and terabytes describe larger amounts of data.

Coder Glossary

The words nobody should have to pretend they understand.

Search a term or browse the full decoder ring.

Algorithm

A step-by-step set of instructions for solving a problem.

API

A defined way for software systems to exchange data or request actions.

Backend

Server-side code, databases, and services behind an interface.

Binary

A number system using only 0 and 1.

Cache

Temporary storage that keeps frequently used data nearby.

Cloud

Computing resources accessed across a network.

Compiler

Software that translates source code into another executable form.

Database

An organized system for storing and retrieving information.

Debugging

Finding, understanding, and fixing problems in code.

DOM

The browser’s object-based representation of an HTML document.

Framework

A reusable structure and set of tools for building software.

Frontend

The part of an app users see and interact with.

Function

A reusable block of code designed to perform a task.

Git

A version-control system that tracks file changes.

HTTP / HTTPS

Protocols used to exchange web resources. HTTPS encrypts the connection.

IDE

An app combining code editing with running and debugging tools.

Loop

A structure that repeats instructions.

Open Source

Software whose source code can be inspected and modified under its license.

Repository

A project location that stores files and version history.

Server

A computer or program that provides data or services.

Variable

A named place used to store a value.

Version Control

A system for recording changes so earlier versions can be restored.
