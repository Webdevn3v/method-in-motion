Did You Know?

Facts that'll blow your mind.

Real facts about coding, computers, and the internet — the kind that make you go "wait, seriously?"

🐛
The First Bug Was Real
In 1947, a moth was found stuck inside a computer at Harvard. Grace Hopper's team taped it into their logbook and wrote "First actual case of bug being found." The word stuck forever.
🌐
The Web Is Only 35 Years Old
Tim Berners-Lee invented the World Wide Web in 1989. The entire internet as we know it is younger than most of your teachers.
🚀
Apollo Had Less Power Than Your Phone
The computer that landed humans on the moon had 4KB of RAM. Your phone has around 8 million times more memory. You are literally holding moon-landing power in your pocket.
🎮
The First Video Game Was in 1958
Tennis for Two was created on an oscilloscope by physicist William Higinbotham — decades before consoles existed. It was deleted after the exhibit ended. Nobody thought it mattered.
👩‍💻
The First Programmer Was a Woman
Ada Lovelace wrote the first computer algorithm in 1843 — for a machine that hadn't even been built yet. She also predicted computers could compose music and create graphics. In 1843.
📱
There Are Over 1.5 Billion Websites
Every single one started as a blank HTML file. The average website takes less than 24 hours to build. Yours could exist by tomorrow.
⚡
JavaScript Was Built in 10 Days
Brendan Eich wrote the first version of JavaScript in just 10 days in 1995. It now runs on 98% of all websites and is one of the most used languages on Earth.
🔢
Computers Only Speak in 1s and 0s
Every image, song, video, game, and message you've ever seen on a screen is just billions of 1s and 0s arranged in a very specific order. That's it. Binary is everything.
🌍
More People Have Phones Than Toilets
Around 7 billion people on Earth have mobile phones. Only 6 billion have access to toilets. Technology spreads faster than plumbing. That's a fact.
History of Coding

How we got here.

From looms and punch cards to AI and quantum computing — the full story of how coding became the most important skill on the planet.

1843
Mathematics
Ada Lovelace Writes the First Algorithm
For Charles Babbage's Analytical Engine — a computer that existed only on paper. Ada saw what machines could do before any machine could actually do it. She is the world's first programmer.
1890
Hardware
Herman Hollerith Invents Punch Cards
To speed up the US Census, Hollerith created machines that read data from punched holes in cards. This became the dominant way to input computer data for over 70 years. His company eventually became IBM.
1936
Theory
Alan Turing Invents the Concept of Computing
Alan Turing's paper "On Computable Numbers" described a theoretical machine that could solve any problem expressible in a mathematical form. This "Turing Machine" is the foundation of every computer ever built.
1940s
Hardware
The First Electronic Computers
ENIAC (1945) filled an entire room with 18,000 vacuum tubes and could do 5,000 additions per second. It weighed 30 tons and required its own cooling system. Your phone does billions of calculations per second.
1957
Languages
FORTRAN — The First High-Level Language
Before FORTRAN, programmers wrote machine code by hand. FORTRAN let scientists write equations that looked almost like math. It was revolutionary — and is still used in scientific computing today.
1969
Internet
ARPANET Sends Its First Message
The US Defense Department connected four university computers. The first message was supposed to be "login." The system crashed after "lo." The internet started with a typo.
1972
Languages
C Language Is Born
Dennis Ritchie created C at Bell Labs to build the Unix operating system. C became the foundation for C++, Java, Python, JavaScript, and almost every modern language. It's still in use everywhere.
1984
Consumer Tech
The Macintosh Changes Personal Computing
Apple's Macintosh introduced the graphical user interface and the mouse to everyday people. Before this, computers had no pictures — just a blinking cursor and a command line. This was the beginning of computers for everyone.
1989
Web
Tim Berners-Lee Invents the World Wide Web
Originally called "Information Management: A Proposal," it was a system to help scientists share research. His boss wrote "Vague but exciting" on the cover. It accidentally became the entire internet.
1995
Languages
JavaScript Created in 10 Days
Netscape hired Brendan Eich with one instruction: make the web interactive, fast. He did it in 10 days. Despite a rocky start, JavaScript became the language of the web. It now runs everywhere — browsers, servers, apps, and robots.
2007
Mobile
The First iPhone Ships
Steve Jobs called it "an iPod, a phone, and an internet communicator" in one device. The audience laughed when he said it. Within five years, smartphones changed how 4 billion people lived every single day.
2022
AI
ChatGPT Reaches 1 Million Users in 5 Days
It took Netflix 3.5 years and Facebook 10 months to reach 1 million users. ChatGPT did it in 5 days. AI moved from science fiction to everyday tool almost overnight. The coders who understand the fundamentals are the ones who'll shape what comes next.
History of Computers

From room-sized to pocket-sized.

The evolution of the machines themselves — from mechanical gears to quantum chips.

⚙️
1822
Babbage's Difference Engine
A hand-cranked mechanical calculator designed to compute mathematical tables. It was never completed in Babbage's lifetime, but a working model was built in 1991 — and it worked perfectly.
💡
1945
ENIAC
The first general-purpose electronic computer. It filled an 1,800 square foot room, consumed 150 kilowatts of power, and had to be rewired by hand to change its program.
🔬
1958
The Transistor Revolution
Vacuum tubes gave way to transistors — tiny switches that could be etched onto silicon chips. This made computers smaller, cheaper, and faster by orders of magnitude. Everything since then is built on this moment.
🖥️
1977
Apple II — The First Home Computer
The Apple II brought computing to homes and schools for the first time. It came with a keyboard, color display, and the ability to run programs. It sold over 5 million units and changed who computers were for.
💾
1981
IBM PC & the Rise of Windows
IBM's personal computer and Microsoft's DOS operating system standardized the industry. IBM's "open architecture" meant anyone could build compatible machines — creating the entire PC industry as we know it.
📱
2007
The Smartphone Era
Modern smartphones contain more computing power than all of NASA had during the Apollo missions combined. The computer in your pocket would have been science fiction 40 years ago.
🧠
2019
Google's Quantum Supremacy
Google's quantum computer solved a calculation in 200 seconds that would take the world's fastest supercomputer 10,000 years. Quantum computing works by harnessing quantum physics — a completely different kind of logic.
⚡
Today
The Cloud Era
Today's computers don't just sit on desks — they exist as vast networks of servers distributed around the world. When you use Google, Netflix, or any app, you're using computing power spread across thousands of machines.
History of the Internet

The network that connected everything.

The internet didn't appear overnight — it was built in layers, each decade adding something new.

1969
ARPANET — Four Computers, One Network
The US military connects computers at UCLA, Stanford, UC Santa Barbara, and University of Utah. The internet begins as a defense project with four nodes. Today there are over 5 billion connected devices.
1972
Email Is Invented
Ray Tomlinson sends the first email between two computers. He also chose the @ symbol to separate user names from machine names — a decision that shapes every email address still used today.
1983
TCP/IP — The Language of the Internet
The internet switches to TCP/IP — the set of rules that still governs how data travels across networks. January 1st, 1983 is considered the official birthday of the modern internet.
1989
The World Wide Web Is Born
Tim Berners-Lee proposes a system of linked documents accessible over the internet. He calls it the World Wide Web. His boss writes "Vague but exciting" on the cover page. It becomes the layer we call "the internet" today.
1993
Mosaic — The First Web Browser
The first browser with images. Before Mosaic, the web was text only. Adding images made it feel like a real experience — and the number of web users exploded from thousands to millions within a year.
1998
Google Launches in a Garage
Larry Page and Sergey Brin start Google as a Stanford PhD project. Their insight: rank pages by how many other pages link to them, not just keywords. This was so obvious in hindsight that it's wild nobody thought of it first.
2004
Social Media Changes Everything
Facebook, YouTube, and later Twitter transform the internet from a place you browse into a place where you participate. Users start creating as much content as they consume. This is where "don't be a consumer, be a creator" starts to mean something real.
2023
The AI Internet
AI tools become widely available. Writing, images, code, music, and video can all be generated in seconds. The internet is now a place where AI and humans create together — and understanding how it all works is more important than ever.
Tech Pioneers

The people who built everything.

Every device, language, and platform you use was created by someone. Here are some of the people who changed everything.

1843 · Mathematics
Ada Lovelace
World's First Programmer
Wrote the first algorithm for a machine that didn't exist yet. She also predicted computers would eventually create graphics and music — 100 years before they could.
1936 · Computer Science
Alan Turing
Father of Computer Science
Invented the theoretical model for all modern computers. During WWII, he cracked the Nazis' Enigma code, shortening the war by an estimated 2 years. His reward was criminal prosecution by the British government. History owes him more than it gave.
1940s · Programming
Grace Hopper
Inventor of the Compiler
A US Navy admiral who invented the first compiler — a program that translates human-readable code into machine code. She also found the first actual computer bug (the moth). She popularized the term "debugging."
1970s · Software
Bill Gates
Co-Founder of Microsoft
Dropped out of Harvard at 19 to start Microsoft. His bet that every home would eventually have a personal computer was considered absurd in 1975. He was right. DOS and Windows became the operating systems of an entire generation.
1976 · Hardware
Steve Wozniak
The Engineer Behind Apple
The quiet genius who actually built the Apple I and Apple II. Wozniak designed a computer so elegant that engineers still study it. He gave the schematics away for free because he wanted everyone to learn. Without Woz, there's no Apple.
1989 · Web
Tim Berners-Lee
Inventor of the World Wide Web
Invented the web and then gave it away — no patents, no fees, no royalties. He could have been a billionaire. Instead he said the web should belong to everyone. He still advocates for an open internet today.
1998 · Search
Larry Page & Sergey Brin
Founders of Google
Started Google as a PhD project at Stanford. They tried to sell it for $1 million in 1998 and nobody bought it. Google is now worth over $1 trillion. The person who passed on that deal probably thinks about it every day.
1984 · Diversity
Katherine Johnson
NASA Mathematician & Hidden Figure
Her orbital calculations were so accurate that astronaut John Glenn refused to launch until she personally verified the computer's numbers. She calculated the trajectory for Apollo 11's moon landing. Her work was classified for decades.
2003 · AI
Geoffrey Hinton
The Godfather of Deep Learning
Spent decades being ignored for his belief that neural networks could learn like brains. When he was finally proven right, AI went from a fringe idea to the biggest technological shift since the internet. He's since spoken publicly about the risks of what he helped create.
Programming Languages

The languages computers speak.

There are over 700 programming languages. Here are the ones that matter most — and why.

Python
Created 1991 · Guido van Rossum
AI, data science, automation, and beginners. Designed to be readable like English. The most popular language in the world right now.
JavaScript
Created 1995 · Brendan Eich
Powers every interactive website. The only language that runs natively in browsers. Also runs on servers, mobile apps, and even robots.
HTML
Created 1991 · Tim Berners-Lee
The structure of every webpage ever made. Not technically a "programming" language but the foundation of the entire web. Nova's specialty.
CSS
Created 1996 · Håkon Wium Lie
Controls how everything looks on the web — colors, fonts, layouts, animations. Without CSS, every website is just plain black text on a white background. Zen's domain.
Java
Created 1995 · James Gosling
"Write once, run anywhere." Used in Android apps, enterprise software, and Minecraft. One of the most taught languages in schools.
Go
Created 2009 · Google
Built for speed and simplicity by Google engineers who were tired of C++. Powers YouTube, Dropbox, and many major cloud systems.
Rust
Created 2010 · Mozilla
Designed to be blazing fast AND safe — almost impossible to write memory bugs in. Used in browsers, operating systems, and is growing fast in AI infrastructure.
Swift
Created 2014 · Apple
Apple's language for building iPhone, iPad, and Mac apps. Replaced Objective-C. Designed to be fast to write and difficult to break. If you use an iPhone, you use Swift every day.
How It Works

What actually happens when you visit a website.

Every time you type a URL, hundreds of things happen in less than a second. Here's the story.

01
You Type a URL
Your browser takes the address (like google.com) and asks a DNS server to translate it into a real IP address — a number like 142.250.80.46. DNS is the internet's phone book.
02
Your Browser Finds the Server
Using that IP address, your browser sends a request to a web server somewhere in the world — possibly thousands of miles away. This round trip often happens in under 50 milliseconds.
03
The Server Sends Back Files
The server responds with HTML, CSS, and JavaScript files. These are just text documents — the same kind you write in a code editor. The magic is in how the browser reads them.
04
The Browser Reads HTML
Your browser reads the HTML top to bottom, building a tree of elements called the DOM (Document Object Model). Every heading, paragraph, and div becomes a node in this tree.
05
CSS Paints the Picture
CSS rules are applied to the DOM — colors, fonts, sizes, positions. The browser calculates exactly how every pixel should look. This process is called "rendering" and it happens dozens of times per second for animations.
06
JavaScript Brings It to Life
JavaScript runs and starts listening for events — clicks, scrolls, keyboard input. When something happens, JS updates the DOM and CSS in real time. That's how websites respond to you without reloading the whole page.
Binary & Data

How computers actually store information.

Every piece of data — text, images, music, video — is stored as numbers. And every number is made of 1s and 0s.

BIT
The Smallest Unit
A bit is a single 1 or 0. That's it. The word comes from "binary digit." Everything a computer stores is made of bits — billions and billions of them.
BYTE
8 Bits = 1 Letter
8 bits make a byte. A byte can represent 256 different values (2 to the power of 8). One byte is enough to store one character of text — like the letter "A."
KB → TB
Scaling Up
1,000 bytes = 1 kilobyte. 1,000 KB = 1 megabyte. 1,000 MB = 1 gigabyte. A typical photo is about 3–5 MB. A movie is about 4 GB. The internet moves about 400 exabytes (400 billion gigabytes) per day.
Glossary

Words every coder should know.

Tech has a language of its own. Here's a decoder ring for the most common terms.

Algorithm
A step-by-step set of instructions for solving a problem. Every recipe, playlist, and search result is powered by an algorithm.
API
Application Programming Interface. A set of rules that lets two programs talk to each other. When an app uses Google Maps, it's using an API.
Backend
The part of a website or app that users never see — the server, database, and logic that power everything behind the scenes.
Binary
A number system with only two digits: 0 and 1. All computer data is stored and processed in binary at the hardware level.
Cache
Temporary storage that saves copies of data so you can access it faster next time. Your browser caches images so websites load quicker on repeat visits.
Cloud
Servers accessed over the internet rather than on your local machine. When you store a photo in iCloud or Google Drive, it's sitting on a server somewhere in a building.
Compiler
A program that translates human-readable code into machine code (0s and 1s) that a computer can actually execute. Grace Hopper invented the first one.
Database
An organized collection of data that can be searched, sorted, and updated. Every app that remembers your preferences or history uses one.
Debugging
The process of finding and fixing errors in code. Bug's entire world. Every programmer spends more time debugging than writing new code.
DOM
Document Object Model. The browser's internal representation of an HTML page as a tree of objects. JavaScript manipulates the DOM to update what you see without reloading the page.
Framework
A pre-built collection of code that gives developers a structure to build apps faster. React, Vue, and Angular are JavaScript frameworks. Think of it as a building's skeleton.
Frontend
Everything the user sees and interacts with directly — the HTML, CSS, and JavaScript in a browser. Zen's territory.
Function
A reusable block of code that performs a specific task. You define it once and can call it as many times as you want. Functions are how code stays organized.
Git
A version control system that tracks changes to code over time. Lets developers collaborate without overwriting each other's work, and roll back mistakes to any previous version.
HTTP / HTTPS
The protocol that browsers and servers use to communicate. The S in HTTPS stands for Secure — it means the connection is encrypted. Always look for the padlock.
IDE
Integrated Development Environment. A fancy text editor for writing code — with built-in tools for running, debugging, and managing projects. VS Code is the most popular one today.
Loop
A block of code that repeats until a condition is met. Loop's entire world. The foundation of automation — making computers do repetitive tasks so humans don't have to.
Open Source
Code that anyone can view, use, and contribute to. Linux, Python, and React are all open source. The internet runs largely on software that was built by volunteers.
Repository (Repo)
A folder where a project's code and its full history of changes are stored. GitHub hosts millions of repos. MiM's site lives in one.
Variable
A named container that holds a value. Like a labeled box. You can put anything in it and change the contents whenever you want. The most fundamental building block in all of coding.
