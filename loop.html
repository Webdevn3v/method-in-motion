Thinking in Patterns
LESSON 01 · CODERS
01 / 05

What Is a Pattern?

A pattern is something that repeats in a predictable way. Stripes on a shirt. Steps in a dance. Computers are pattern machines. When you recognize a pattern, you know what to automate.

02 / 05

Why Computers Love Repetition

A loop is the tool that lets you tell a computer: "Do this action, over and over, until I say stop." It's one of the most powerful ideas in all of programming.

03 / 05

Sequences Come First

Before loops, there are sequences — a list of steps in order. Code runs top to bottom, one line at a time.

// A sequence — each step in order let egg = "cracked"; let batter = "mixed"; let result = "cooked";
04 / 05

Loops Are Patterns in Code

Instead of writing the same line 10 times, you write it once inside a loop.

for (let i = 1; i <= 3; i++) {   console.log("Step " + i); }
05 / 05

Flow Is the Big Idea

Programming isn't just about commands — it's about controlling the flow of those commands. You're designing the path the computer follows.

Key Terms
LESSON 01 · TAP TO EXPAND
Pattern ›
Something that repeats in a predictable way. A signal to use a loop instead of repeating code.
Sequence ›
Steps in a specific order. Code runs top to bottom, one line at a time.
Loop ›
A block of code that runs repeatedly until a condition tells it to stop.
Flow ›
The path a program follows as it runs.
Iteration ›
One single pass through a loop.
Automate ›
To make a computer do a task without doing it manually each time.

For Loops
LESSON 02 · CODERS
01 / 05

Anatomy of a For Loop

A for loop has three parts: where to start, when to stop, and how to step forward.

for (let i = 0; i < 5; i++) {   // runs 5 times: i = 0, 1, 2, 3, 4   console.log(i); }
02 / 05

The Counter Variable

The variable i is a counter. It changes with every iteration.

03 / 05

Using i Inside the Loop

Because i changes each time, you can use it inside the loop body to create dynamic output.

04 / 05

Looping Over an Array

Use i as the index to access each item one at a time in a list (array).

let crew = ["Loop", "Zen", "Nova", "Byte"]; for (let i = 0; i < crew.length; i++) {   console.log(crew[i]); }
05 / 05

Counting Down

You can count backwards using i--.

Key Terms
LESSON 02 · TAP TO EXPAND
for loop ›
A loop with a built-in counter — you define the start, stop, and step.
Counter variable ›
Usually named i, tracks which iteration the loop is on.
Array ›
A list of values stored in one variable, zero-indexed.
Index ›
The position of an item in an array, starting at 0.
i++ / i-- ›
Shorthand for adding or subtracting 1 from i each pass.
.length ›
Tells you how many items are in an array.

Conditionals & Flow Control
LESSON 03 · CODERS
01 / 05

Making Decisions in Code

An if statement checks whether something is true, and only runs a block of code if it is.

if (temperature > 80) {   console.log("Wear sunscreen!"); }
02 / 05

if / else

Add an else block to handle the case when the condition is false.

03 / 05

else if — More Than Two Paths

Code checks each condition in order and runs the first block where the condition is true.

04 / 05

Conditionals Inside Loops

You can put an if statement inside a loop to check a condition on every item.

05 / 05

Comparison Operators

Conditions use operators like ===, !==, >, <, >=, <=.

Key Terms
LESSON 03 · TAP TO EXPAND
Conditional ›
A statement that only runs if a condition is true.
if statement ›
Checks a condition, runs code if true.
else ›
The block that runs when if is false.
else if ›
Adds more branches, checked in order.
Boolean ›
A value that is either true or false.
=== vs == ›
=== checks value AND type. Always prefer ===.

Flow Challenge
LESSON 04 · CODERS
01 / 04

Putting It All Together

Real programs layer loops inside loops, conditions inside loops, and conditions that decide whether a loop even runs.

02 / 04

While Loops

A while loop keeps running as long as a condition stays true. Use it when you don't know exactly how many times the loop needs to run.

let energy = 10; while (energy > 0) {   console.log("Energy: " + energy);   energy -= 3; }
03 / 04

Nested Loops

A loop inside another loop is called a nested loop. This is how you work with grids and tables.

04 / 04

break and continue

break exits a loop immediately. continue skips the rest of the current iteration.

∞ Symbols Reference

Holds the loop's start, stop, and step.
;
Separates the 3 parts of a for loop.
< / <=
Less than / less than or equal — controls the stop condition.
++ / --
Increment / decrement — the step.
