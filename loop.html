Thinking in Patterns
LESSON 01 · CODERS
01 / 09

What Is a Pattern?

A pattern is something that repeats in a predictable way: stripes on a shirt, steps in a dance, days on a calendar. Computers are pattern machines. When you recognize a repeated action, you can ask: Could code do this for me?

02 / 09

Sequence vs. Loop

Sequence = Do A, then B, then C. A sequence follows steps in order. Loop = Repeat A until the rule says stop. Both control flow, but one moves forward through different steps while the other repeats a pattern.

03 / 09

First, See the Repetition

Imagine telling the computer to jump three times. You could write the same instruction three separate times:

console.log("Jump");
console.log("Jump");
console.log("Jump");

Breaking Down These Lines

console.log tells JavaScript to print a message.
( ) holds the message we are giving to console.log.
"Jump" is text, so it is wrapped in quotes.
; marks the end of each instruction.
The computer sees three separate instructions. We see one repeating pattern.

04 / 09

Loops Turn Repetition Into a Rule

Instead of repeating the same line manually, a loop lets us write the action once and give the computer a rule for how many times to repeat it.

for (let i = 1; i <= 3; i++) {
  console.log("Jump");
}

Breaking Down This Loop

for — tells JavaScript we are about to repeat.
( ) — holds the loop instructions.
let i = 1 — START at 1. let creates a variable; i is the counter.
i <= 3 — CHECK: keep going while the counter is 3 or less.
i++ — STEP: add 1 after each pass.
{ } — wraps the code that repeats.
console.log("Jump") — the DO/action.

05 / 09

Loop's Core Memory Rule

START → CHECK → DO → STEP → REPEAT.

Start somewhere. Check whether you should keep going. Do the action. Move one step. Then check again. This is the path underneath every basic loop you will read in this course.

06 / 09

What Is an Iteration?

Each single trip through the loop is called an iteration. In the Jump loop above: i = 1 is iteration 1, i = 2 is iteration 2, and i = 3 is iteration 3. Three iterations means the repeated action runs three times.

07 / 09

Sequences Still Matter

Loops do not replace sequences. Programs often use both: a sequence tells the computer what order to follow, while loops tell it what to repeat.

let egg = "cracked";
let batter = "mixed";
let result = "cooked";

Breaking Down These Lines

let creates a variable.
egg / batter / result are variable names — labels for stored information.
= stores a value inside a variable.
The lines run top to bottom: crack → mix → cook. That is a sequence.

08 / 09

Patterns Help You Predict

Before running code, ask: What repeats? Where does it start? What makes it stop? What changes each time? Prediction is a coding skill. The more accurately you can predict a loop, the easier it becomes to debug one.

09 / 09

Flow Is the Big Idea

Programming is not just a pile of commands. It is a path. Sequences control order. Loops control repetition. Later, conditions will control decisions. Together, they create program flow.

Key Terms
LESSON 01 · TAP TO EXPAND
Pattern ›
Something that repeats in a predictable way. A signal to use a loop instead of repeating code.
Sequence ›
Steps in a specific order. Code runs top to bottom, one line at a time.
Loop ›
A block of code that runs repeatedly until a condition tells it to stop.
Flow ›
The path a program follows as it runs.
Iteration ›
One single pass through a loop.
Automate ›
To make a computer do a task without doing it manually each time.

For Loops
LESSON 02 · CODERS
01 / 11

The Three Zones: START · CHECK · STEP

A for loop is built around three instructions inside its parentheses. Loop's memory rule expands them into the full cycle: START → CHECK → DO → STEP → REPEAT.

for (let i = 0; i < 5; i++) {
  console.log(i);
}

Breaking Down the Shape

for = repeat using a controlled pattern.
( ) = holds START, CHECK, and STEP.
; = separates those three zones.
{ } = holds the DO/action that repeats.

02 / 11

ZONE 1 — START

let i = 0

let creates a variable. i is the counter. = 0 gives it a starting value. Programmers often start at 0 because arrays number their first position as 0.

03 / 11

ZONE 2 — CHECK / STOP RULE

i < 5

This is a question that becomes true or false. While it is true, the loop continues. When it becomes false, the loop stops.

Important: i < 5 allows 0, 1, 2, 3, 4 — not 5. Five is where the check becomes false.

04 / 11

ZONE 3 — STEP / UPDATE

i++

This runs after each iteration. i++ means add 1 to i. It is shorthand for i = i + 1.

Breaking Down the Symbols

i = the current counter value.
++ = increase by one.
This STEP is what moves the loop toward its stopping point.

05 / 11

Trace the Loop One Pass at a Time

i = 0 → 0 < 5? yes → run
i = 1 → 1 < 5? yes → run
i = 2 → 2 < 5? yes → run
i = 3 → 3 < 5? yes → run
i = 4 → 4 < 5? yes → run
i = 5 → 5 < 5? no → STOP

The loop body runs five times, even though the final checked value reaches 5. The final check stops the loop before the body runs again.

06 / 11

i Is Not Magic

i is only a variable name. You could call it step, index, or another useful name.

for (let step = 1; step <= 3; step++) {
  console.log(step);
}

Breaking Down This Variation

step = 1 starts at 1.
step <= 3 allows 1, 2, and 3.
step++ adds one after each pass.
The name changed, but the START/CHECK/STEP pattern stayed the same.

07 / 11

Dynamic Output Changes With the Counter

console.log("Lap " + i);

The text "Lap " stays the same. The value of i changes each iteration, so the output becomes Lap 0, Lap 1, Lap 2, and so on.

Breaking Down This Line

"Lap " is fixed text.
+ joins values together here.
i contributes the current counter value.

08 / 11

Arrays: Ordered Lists With Numbered Positions

An array is an ordered list. Square brackets [ ] hold the items. Each item has an index, and JavaScript starts counting those positions at 0.

let crew = ["Loop", "Zen", "Nova"];
crew[0] // "Loop"
crew[1] // "Zen"
crew.length // 3 items

Breaking Down the Array

[ ] holds the list items.
crew[0] asks for the item at position 0 — the first item.
.length tells us how many items are in the list.

09 / 11

Why i < crew.length Works

for (let i = 0; i < crew.length; i++) {
  console.log(crew[i]);
}

For a 3-item array, valid indexes are 0, 1, and 2. crew.length is 3, so i < crew.length stops before i becomes an invalid index. This is why < is so common when looping through arrays.

10 / 11

Counting Down

for (let i = 5; i >= 1; i--) {
  console.log(i);
}

START: 5. CHECK: stay at or above 1. STEP: i-- subtracts 1. Compare: i++ moves up; i-- moves down.

11 / 11

Course Hazards

Forgot the update? A loop may never stop.
Used <= crew.length? You may go one index too far and get undefined.
Mixed up < and <=? You may run one time too many or too few.
Wrong direction? Check whether you need ++ or --.

Key Terms
LESSON 02 · TAP TO EXPAND
for loop ›
A loop with a built-in counter — you define the start, stop, and step.
Counter variable ›
Usually named i, tracks which iteration the loop is on.
Array ›
A list of values stored in one variable, zero-indexed.
Index ›
The position of an item in an array, starting at 0.
i++ / i-- ›
Shorthand for adding or subtracting 1 from i each pass.
.length ›
Tells you how many items are in an array.

Conditionals & Flow Control
LESSON 03 · CODERS
01 / 10

Decisions Have Rules

Real life is full of conditions: If it is raining, take an umbrella. Else, leave it home. Code can follow the same kind of decision rule.

02 / 10

Meet the if Statement

if (temperature > 80) {
  console.log("Wear sunscreen!");
}

Breaking Down This if Statement

if = ask a question.
(temperature > 80) = the condition.
> = comparison operator meaning greater than.
The condition becomes true or false.
{ } = the code that runs only when the condition is true.

03 / 10

Boolean = True or False

A Boolean has only two possible values: true or false. Conditions produce Boolean answers.

10 > 5 // true
3 > 8 // false

Breaking Down These Checks

JavaScript compares the value on the left with the value on the right. It does not print a sentence answer — it evaluates the comparison as true or false.

04 / 10

if / else = Two Paths

Think of a fork in the course. if = Path A. else = Path B. Exactly one path runs.

if (score >= 10) {
  console.log("Level unlocked");
} else {
  console.log("Keep going");
}

Breaking Down the Two Paths

If score >= 10 is true, the first block runs and the else block is skipped. If it is false, JavaScript skips the first block and runs else.

05 / 10

else if = More Than Two Paths

if (score >= 90) {
  console.log("Gold");
} else if (score >= 70) {
  console.log("Silver");
} else {
  console.log("Keep training");
}

Conditions are checked top to bottom. The first true branch wins. Later branches are skipped.

Trace score = 82

82 >= 90? false → keep checking.
82 >= 70? true → print “Silver.”
Stop checking the remaining branches.

06 / 10

Conditionals Inside Loops

for (let i = 1; i <= 5; i++) {
  if (i === 3) {
    console.log("Checkpoint!");
  }
}

The loop visits 1, 2, 3, 4, 5. The condition is checked on every iteration. Only when i equals 3 does it become true, so “Checkpoint!” prints once.

07 / 10

Comparison Operators

=== exactly equal · !== not equal · > greater than · < less than · >= greater than or equal · <= less than or equal.

08 / 10

One = Stores. Three === Asks.

let score = 10; // store 10
score === 10 // ask: exactly equal? true

= assigns or stores a value. === compares and asks a true/false question. You may see == in older code, but prefer === because it compares both value and type.

09 / 10

Combine Conditions Carefully

You may eventually see && (AND), || (OR), and ! (NOT). They combine or flip Boolean conditions.

age >= 8 && hasPass === true // both must be true

Keep the memory simple: AND needs both, OR needs either, NOT flips true/false.

10 / 10

Loop's Decision Rule

CONDITION → TRUE PATH or FALSE PATH. Read the condition like a question before reading the code blocks. Predict which path runs, then test your prediction.

Key Terms
LESSON 03 · TAP TO EXPAND
Conditional ›
A statement that only runs if a condition is true.
if statement ›
Checks a condition, runs code if true.
else ›
The block that runs when if is false.
else if ›
Adds more branches, checked in order.
Boolean ›
A value that is either true or false.
= vs === ›
= stores/assigns a value. === compares and asks whether two values match exactly.

Flow Challenge
LESSON 04 · CODERS
01 / 09

Put the Whole Path Together

Sequences control order. Loops control repetition. Conditions control decisions. Real programs combine all three to create flow: the path the computer follows from one instruction to the next.

02 / 09

For vs. While

Use a for loop when the START / CHECK / STEP pattern is clear or the repeat count is predictable. Use a while loop when repetition mainly depends on a condition and you may not know exactly how many passes you need.

03 / 09

While Loops

let energy = 10;
while (energy > 0) {
  console.log("Energy: " + energy);
  energy -= 3;
}

Breaking Down This While Loop

let energy = 10 — creates the changing value before the loop.
while (energy > 0) — CHECK before each pass.
{ } — body runs only while the condition is true.
energy -= 3 — changes energy by subtracting 3, moving the loop toward false.
When energy is no longer greater than 0, the loop stops.

04 / 09

While Safety: Something Must Change

If the value used by a while condition never changes, the condition may stay true forever. That creates an infinite loop. Always ask: What changes each pass so this can eventually stop?

05 / 09

Nested Loops Build Grids

A loop inside another loop is a nested loop. Think of a grid: the outer loop = rows, the inner loop = columns.

for (let row = 1; row <= 3; row++) {
  for (let col = 1; col <= 3; col++) {
    console.log(row, col);
  }
}

Breaking Down the Grid

The outer loop chooses a row. For every one outer-loop step, the inner loop completes all of its column steps. Row 1 gets columns 1,2,3; then row 2 gets 1,2,3; then row 3 gets 1,2,3.

06 / 09

break = Exit the Loop Completely

let items = ["key", "map", "gem", "rope"];
for (let i = 0; i < items.length; i++) {
  if (items[i] === "gem") { break; }
}

break means: stop the entire loop now. Once the gem is found, there is no reason to keep searching.

07 / 09

continue = Skip This Pass, Keep Looping

for (let i = 1; i <= 5; i++) {
  if (i === 3) { continue; }
  console.log(i);
}

continue skips the rest of the current iteration, then moves to the next pass. This prints 1, 2, 4, 5 — only 3 is skipped.

08 / 09

Predict Before You Run

Before pressing Run, ask: What prints? How many iterations happen? Where does it stop? Which branch runs? Predicting flow forces you to mentally execute the code — one of the fastest ways to become a stronger programmer.

09 / 09

Flow Control Is Choosing the Path

for, while, if, break, and continue all change the path code follows. The goal is not to memorize symbols alone. It is to see the path before the computer runs it.

Key Terms
LESSON 04 · TAP TO EXPAND
while loop ›
Repeats while a condition remains true; useful when the exact number of passes is not known ahead of time.
Nested loop ›
A loop inside another loop.
Outer loop ›
The outside loop in a nested structure; often controls rows or larger groups.
Inner loop ›
The loop inside another loop; completes all its passes for each outer-loop iteration.
break ›
Exits the current loop completely.
continue ›
Skips the rest of the current iteration and moves to the next pass.
Infinite loop ›
A loop that never reaches a stopping condition.
Flow control ›
Tools that control which path code follows, what repeats, and when execution stops or skips.

∞ Core Memory Rule

START → CHECK → DO → STEP → REPEAT
Map it onto for (let i = 0; i < 5; i++) { /* action */ }. Start at 0, check i < 5, do the body, add 1, repeat.
Iteration
One complete pass through a loop.
Flow
The path a program follows. Sequences control order, loops repetition, conditionals decisions.

∞ Full For-Loop Anatomy

for
Begin a controlled repetition pattern.
let i = 0
START. Create the counter and give it its first value.
i < 5
CHECK/STOP rule. True = run; false = stop. Values are 0-4, not 5.
i++
STEP. Add 1 after each pass. Same idea as i = i + 1. Use i-- to subtract 1.
{ }
The repeated body — the DO/action.

∞ Comparisons + Booleans

true / false
Boolean values: the two possible answers produced by a condition.
=== / !==
Exactly equal / not equal.
> < >= <=
Greater than, less than, greater/less than or equal.
= vs ===
One = stores. Three === asks. = assigns a value; === compares.
&& || !
AND / OR / NOT — combine or flip Boolean conditions.

∞ Arrays + Index

Array
let crew = ["Loop","Zen","Nova"] — an ordered list inside square brackets.
Index
crew[0] is "Loop". Array positions start at 0.
.length
crew.length is 3. i < crew.length visits valid indexes 0,1,2 without overshooting.

∞ Conditionals

if
if (condition) { } — runs when the condition is true.
else if
Adds another condition. Checked top to bottom; the first true branch wins.
else
Fallback path when earlier conditions are false.
Decision rule
CONDITION → TRUE PATH or FALSE PATH.

∞ For vs While + Safety

for
Best when START/CHECK/STEP is known or predictable.
while
Best when repetition mainly depends on a condition and the exact count may be unknown.
Infinite loop
If the value controlling a while condition never changes, the loop may never stop.

∞ Nested Loops + Flow Control

Outer / Inner
Grid memory: outer = rows, inner = columns. For each outer pass, the inner loop completes all its passes.
break
EXIT the loop completely.
continue
SKIP this pass and keep looping.

∞ Common Loop Bugs / Debug Box

One too many?
Check < vs <=.
undefined?
Check the array index and .length.
Never stops?
Check the STEP/update. Is the condition moving toward false?
Wrong direction?
Check ++ vs --.
Branch never runs?
Test the condition with values you know should be true and false.
