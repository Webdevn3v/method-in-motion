"I don't rush. I watch. Every system has a rhythm — a set of steps that repeats. Find the pattern and you find the shortcut."

A pattern is something that repeats in a predictable way. Stripes on a shirt. The days of the week. The way traffic lights cycle through red, yellow, green. Your morning routine. The chorus of a song.

In coding, patterns are everything. When a computer does the same thing over and over, it's following a pattern. When you write code that repeats, you're creating a pattern on purpose. The ability to spot patterns — and build them — is one of the most powerful skills in all of programming.

Loop sees patterns in everything. Not because they're magic, but because they slow down and look. That's the whole skill. You can learn it too.

📚
Key Terms
Pattern
A set of elements that repeats in a predictable, consistent way.
Example: 1, 2, 3, 1, 2, 3, 1, 2, 3 — the numbers 1-2-3 repeat as a pattern.
Repetition
Doing the same thing more than once. In coding, repetition is powerful — you write instructions once and the computer can follow them a million times.
Example: A website loading the same card layout for every product in a store.
Rule
The logic behind a pattern — what makes it repeat the way it does. Finding the rule is the same as understanding the pattern.
Example: In 2, 4, 6, 8 — the rule is "add 2 each time."
Algorithm
A step-by-step set of instructions for solving a problem. Algorithms often use patterns to work efficiently.
Example: The steps you follow every morning to get ready — that's an algorithm.

Sequences & Order

Order matters. A sequence is a pattern where each step only makes sense because of what came before it.

↻
Sparks · Builders · Coders
This lesson is for members
Join the crew to unlock Lesson 2 and keep flowing with Loop.
📖
Read · 3 min

"A sequence isn't just a list. It's a list where order is everything. Change the order and you change the result — or break it completely."

A sequence is a set of steps that must happen in a specific order to get the right result. Making breakfast is a sequence — you don't eat the eggs before you cook them. Getting dressed is a sequence — you put on socks before shoes.

In code, sequences are the backbone of everything. Every program is, at its core, a sequence of instructions the computer follows one after another. The computer is extremely literal — it does exactly what you tell it, in exactly the order you tell it.

Understanding sequences means understanding that order is logic. When something doesn't work, often the problem is that you have the right steps in the wrong order.

📚
Key Terms
Sequence
A set of steps or instructions that must be followed in a specific order to produce the correct result.
Example: Log in → open app → find lesson → start learning. That's a sequence.
Order of Operations
The rule that determines which steps happen first when multiple things could happen at once.
Example: In math, multiplication happens before addition: 2 + 3 × 4 = 14, not 20.
Step
One single instruction in a sequence. Each step does exactly one thing and sets up the next step.
Example: "Open the file" is one step. "Read the file" is the next step.
Dependency
When one step requires a previous step to have happened first. Dependencies are why order matters.
Example: You can't read a file you haven't opened yet — reading depends on opening.
⚡
See It Live · Order Matters

Lesson 03 · Builders+

Loops in Code

A loop lets you write instructions once and run them as many times as you need. It's the most efficient idea in programming.

↻
Builders · Coders
This lesson is for Builders and up
Upgrade to unlock Lesson 3 — where patterns become actual code loops.
📖
Read · 3 min

"Why do the same thing 100 times when you can write it once and tell the computer to repeat it? That's not laziness. That's efficiency. That's a loop."

A loop is a block of code that runs over and over until a condition is met. Instead of writing the same line 10 times, you write it once and tell the computer "do this 10 times." The computer handles the rest.

The most common type is a for loop — it repeats a block of code a specific number of times. You set a counter, tell it where to start, when to stop, and how to count. Then it runs.

Loops are used everywhere — loading posts in a social media feed, processing items in a shopping cart, drawing every pixel on a screen. Almost everything you interact with online was built with loops at its core.

📚
Key Terms
Loop
A block of code that repeats automatically until a specified condition is no longer true.
Example: for (let i = 0; i < 5; i++) — runs the code inside 5 times.
For Loop
The most common loop. Has three parts: a starting value, a condition to keep running, and an update that happens each time.
Example: for (let i = 1; i <= 3; i++) runs when i is 1, 2, and 3.
Counter / Iterator
A variable that tracks how many times the loop has run. Usually named i, j, or count.
Example: In for (let i = 0; ...), i starts at 0 and increases each loop.
Condition
The rule that determines whether the loop runs again. When the condition becomes false, the loop stops.
Example: i < 5 — keep looping as long as i is less than 5.
Infinite Loop
A loop whose condition never becomes false — so it runs forever. Usually a bug, not intentional.
Example: while (true) — runs forever unless you have a break inside.

Lesson 04 · Coders Only

Build a Pattern Algorithm

You know patterns. You know sequences. You know loops. Now build something real — an algorithm that generates a pattern using all three.

↻
Coders
This lesson is for Coders
The final lesson is reserved for Coders. Upgrade to build a real pattern algorithm from scratch.

Read · 2 min

"An algorithm isn't magic. It's just a plan. Step by step. With a loop at the heart of it."

An algorithm is a complete, step-by-step plan for solving a problem. Every algorithm has three things: inputs (what it starts with), a process (what it does, usually with loops), and outputs (what it produces).

In this lesson, you're going to build an algorithm that generates a number pattern. You'll define the starting point, write the loop, and decide the rule. By the end, you'll have created something that produces infinite patterns — just by changing the numbers.

This is how real programmers think. Not "how do I write this line" — but "what's the pattern, what's the loop, what's the output." Step back. See the flow. Let Loop guide you.

📚
Key Terms
Input
The starting data an algorithm receives to work with.
Example: A starting number like 2, and a rule like "multiply by 2 each time."
Output
The result the algorithm produces after processing the input.
Example: 2, 4, 8, 16, 32 — the pattern the algorithm generates.
Iteration
One single pass through a loop. Each iteration does the work once and updates the counter.
Example: If a loop runs 5 times, it has 5 iterations.
Accumulator
A variable that collects or builds up a result across multiple iterations of a loop.
Example: A variable that adds up all numbers in a list as the loop runs.
