Thinking in Patterns
LESSON 01 · FREE
01 / 05

What Is a Pattern?

A pattern is something that repeats in a predictable way. Stripes on a shirt. Steps in a dance. The way your day has a routine — wake, eat, learn, sleep. Computers are pattern machines. When you recognize a pattern, you know what to automate.

02 / 05

Why Computers Love Repetition

Humans get bored and tired doing the same thing 1,000 times. Computers don't. A loop is the tool that lets you tell a computer: "Do this action, over and over, until I say stop." It's one of the most powerful ideas in all of programming.

03 / 05

Sequences Come First

Before loops, there are sequences — a list of steps in order. Code runs top to bottom, one line at a time. Think of a recipe: first you crack eggs, then you mix, then you cook. Skipping a step or going out of order changes the result.

// A sequence — each step in order let egg = "cracked"; let batter = "mixed"; let result = "cooked";
04 / 05

Loops Are Patterns in Code

Instead of writing the same line 10 times, you write it once inside a loop. The loop counts for you, repeats for you, and stops when you tell it to. Less code. More power.

// Without a loop — messy console.log("Step 1"); console.log("Step 2"); console.log("Step 3"); // With a loop — clean for (let i = 1; i <= 3; i++) { console.log("Step " + i); }
05 / 05

Flow Is the Big Idea

Programming isn't just about commands — it's about controlling the flow of those commands. Which lines run? In what order? How many times? You're not just writing instructions. You're designing the path the computer follows.

Key Terms
LESSON 01 · TAP TO EXPAND
Pattern ›
Something that repeats in a predictable way. In coding, patterns are opportunities to use loops instead of writing the same code over and over.
Sequence ›
Steps in a specific order. Code runs as a sequence — line by line, top to bottom, unless a loop or condition changes the flow.
Loop ›
A block of code that runs repeatedly until a condition tells it to stop. Loops save you from writing the same lines over and over.
Flow ›
The path a program follows as it runs. Controlling flow means deciding which lines execute, how many times, and in what order.
Iteration ›
One single pass through a loop. If a loop runs 5 times, it completes 5 iterations.
Automate ›
To make a computer do a task without doing it manually each time. Loops are one of the main tools for automation.

For Loops
LESSON 02 · SPARKS+
01 / 05

Anatomy of a For Loop

A for loop has three parts inside its parentheses: where to start, when to stop, and how to step forward. Each part is separated by a semicolon.

for (let i = 0; i < 5; i++) { // runs 5 times: i = 0, 1, 2, 3, 4 console.log(i); }
02 / 05

The Counter Variable

The variable i is a counter. It starts at a number you choose, changes with every iteration, and the loop checks it against your stop condition before each pass. When the condition is false, the loop exits.

03 / 05

Using i Inside the Loop

Because i changes each time, you can use it inside the loop body to create dynamic output. That's what makes loops so powerful — the same line of code produces different results each iteration.

for (let i = 1; i <= 5; i++) { console.log("Lap " + i + " complete!"); } // Lap 1 complete! // Lap 2 complete! ...
04 / 05

Looping Over an Array

One of the most common uses of a for loop is going through every item in a list (called an array). Use i as the index to access each item one at a time.

let crew = ["Loop", "Zen", "Nova", "Byte"]; for (let i = 0; i < crew.length; i++) { console.log(crew[i] + " is in the crew."); }
05 / 05

Counting Down

Loops don't have to go up. You can count backwards by starting high and subtracting from i each time using i--.

for (let i = 5; i >= 1; i--) { console.log(i + "..."); } console.log("Launch!");
Key Terms
LESSON 02 · TAP TO EXPAND
for loop ›
A loop with a built-in counter. You define the start, stop, and step — the loop handles the rest.
Counter variable ›
Usually named i, this variable tracks which iteration the loop is on. It changes with each pass.
Array ›
A list of values stored in one variable. Example: ["Zen", "Loop", "Nova"]. Arrays are zero-indexed — the first item is at position 0.
Index ›
The position of an item in an array. Arrays start at index 0. So crew[0] is the first item.
i++ / i-- ›
Shorthand for "add 1 to i" or "subtract 1 from i." These are the step expressions in a for loop.
.length ›
A property of arrays that tells you how many items are inside. Using array.length as your stop condition means the loop always covers every item.

Conditionals & Flow Control
LESSON 03 · BUILDERS+
01 / 05

Making Decisions in Code

Code doesn't just run in a straight line. Sometimes you need it to make a choice. An if statement checks whether something is true, and only runs a block of code if it is.

if (temperature > 80) { console.log("Wear sunscreen!"); }
02 / 05

if / else

Add an else block to handle the case when the condition is false. Now your code has two possible paths — it picks one depending on the situation.

if (score >= 70) { console.log("You passed!"); } else { console.log("Try again."); }
03 / 05

else if — More Than Two Paths

Use else if to add more branches. Code checks each condition in order and runs the first block where the condition is true. If nothing matches, the final else runs (if you have one).

if (score >= 90) { console.log("A"); } else if (score >= 80) { console.log("B"); } else if (score >= 70) { console.log("C"); } else { console.log("Below passing"); }
04 / 05

Conditionals Inside Loops

You can put an if statement inside a loop. This lets you check a condition on every item as the loop runs — filtering, sorting, or responding differently to different values.

let scores = [82, 55, 91, 68]; for (let i = 0; i < scores.length; i++) { if (scores[i] >= 70) { console.log(scores[i] + ": Pass"); } else { console.log(scores[i] + ": Fail"); } }
05 / 05

Comparison Operators

Conditions use comparison operators to evaluate relationships. These are the building blocks of every decision in your code.

=== // strictly equal !== // not equal > // greater than < // less than >= // greater than or equal <= // less than or equal
Key Terms
LESSON 03 · TAP TO EXPAND
Conditional ›
A statement that only runs if a condition is true. The most common is if.
if statement ›
Checks a condition. If it's true, runs the block of code inside the curly braces. If false, skips it.
else ›
The block that runs when the if condition is false. Gives code a second path to follow.
else if ›
Adds more branches between if and else. Each one is checked in order until one is true.
Boolean ›
A value that is either true or false. Conditions always evaluate to a boolean.
=== vs == ›
=== checks value AND type (recommended). == only checks value and can cause unexpected results. Always use ===.

Flow Challenge
LESSON 04 · CODERS
01 / 04

Putting It All Together

You know sequences, loops, and conditionals. Now it's time to combine them. Real programs aren't one concept at a time — they layer loops inside loops, conditions inside loops, and conditions that decide whether a loop even runs.

02 / 04

While Loops

A while loop keeps running as long as a condition stays true. Unlike a for loop, there's no built-in counter — you manage it yourself. Use while loops when you don't know exactly how many times the loop needs to run.

let energy = 10; while (energy > 0) { console.log("Energy: " + energy); energy -= 3; // decrease by 3 each time }
03 / 04

Nested Loops

A loop inside another loop is called a nested loop. The inner loop runs all the way through for every single step of the outer loop. This is how you work with grids, tables, and multi-dimensional data.

for (let row = 1; row <= 3; row++) { for (let col = 1; col <= 3; col++) { console.log("Row " + row + " Col " + col); } }
04 / 04

break and continue

break exits a loop immediately. continue skips the rest of the current iteration and moves to the next one. These give you precise control inside loops — stop when you find what you're looking for, or skip items that don't qualify.

for (let i = 0; i < 10; i++) { if (i === 5) break; // stop at 5 if (i % 2 === 0) continue; // skip even numbers console.log(i); // prints: 1, 3 }
