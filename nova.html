📖 Read

HTML stands for HyperText Markup Language. It's the skeleton of every webpage — the structure that holds everything together before style or code makes it move.

HTML uses tags to label content. Tags are keywords wrapped in angle brackets like <h1> or <p>. Most tags come in pairs — an opening tag and a closing tag with a slash: <p>Hello!</p>.

When a browser reads your HTML, it builds the page from top to bottom — like following Nova's blueprint. Every element lives inside a parent element, creating a nested structure called the DOM tree.

The root of every HTML page looks the same: an <html> tag wraps everything. Inside lives a <head> (info the browser needs but doesn't show) and a <body> (everything the visitor sees).

📝 Key Terms ▾
HTML
HyperText Markup Language — the standard language used to create the structure of web pages.
Tag
A keyword wrapped in angle brackets, like <p>, that tells the browser what kind of content follows.
Element
A complete HTML unit — an opening tag, content, and closing tag together. Example: <h1>Hello</h1>.
Nesting
Placing one element inside another, like how a <p> tag lives inside a <div>.
<head>
The section of an HTML page that holds page info (title, links) but doesn't display on screen.
<body>
The section that holds everything visitors actually see on the page.
DOM
Document Object Model — the browser's internal tree-like map of your HTML page.
Attribute
Extra info added inside a tag. Example: <a href="url"> — href is the attribute.
Nova's Code Blueprint 
<!-- Basic HTML page structure -->
<!DOCTYPE html>
<html lang="en">

  <head>
    <title>Nova's First Page</title>
  </head>

  <body>
    <h1>Welcome to My Page!</h1>
    <p>I built this with HTML.</p>
  </body>

</html>

The indents aren't required, but they help you read the structure at a glance. Notice how everything is nested inside <html>, and visible content sits inside <body>.

📖 Read

Links and images are what turn a page into a real website. The <a> anchor tag creates a clickable link. Its href attribute tells the browser where to go.

Images use the <img> tag — it's self-closing, meaning no closing tag needed. The src attribute points to the image file, and alt describes it for screen readers.

HTML5 gave us semantic elements — tags with meaning. Instead of just <div> everywhere, we use <header>, <nav>, <main>, <section>, and <footer>. These help browsers, search engines, and screen readers understand your page layout at a glance.

Lists are also huge in web design. <ul> creates a bulleted (unordered) list. <ol> creates a numbered (ordered) list. Each item uses <li> inside.

📝 Key Terms ▾
<a href>
Anchor tag — creates a clickable hyperlink. The href attribute is the destination URL.
<img src>
Image element — self-closing tag that displays a picture. src points to the file.
alt attribute
Text description of an image, read by screen readers and shown if image fails to load.
Semantic HTML
Tags that describe their purpose: <nav>, <header>, <main>, <footer>, <article>.
<ul> / <ol>
Unordered (bulleted) and ordered (numbered) list containers.
<li>
List item — goes inside <ul> or <ol> for each entry.
Self-closing
Tags that don't need a closing pair: <img>, <br>, <hr>, <input>.
target="_blank"
Attribute on <a> that opens the link in a new browser tab.
Links, Images & Sections 
<nav>
  <a href="index.html">Home</a>
  <a href="about.html">About</a>
</nav>

<main>
  <h1>My Portfolio</h1>
  <img src="photo.jpg" alt="My photo">

  <ul>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
  </ul>
</main>

<footer>Made with ❤️ and HTML</footer>

Notice the semantic structure — <nav>, <main>, and <footer> each have a clear purpose. Screen readers and Google both understand this layout without extra hints.

📖 Read

Forms are how websites collect information. A <form> element wraps all the inputs together. The action attribute tells the form where to send data, and method controls how (GET vs POST).

Inside a form, <input> is the workhorse. Change its type attribute and you get completely different controls — text boxes, checkboxes, radio buttons, date pickers, file uploaders, and more.

Every input should have a <label>. Use the for attribute on the label and the matching id on the input to connect them. This makes forms accessible and clickable.

<button> elements trigger form submission or run JavaScript. The type="submit" button sends the form; type="button" just fires events without submitting.

📝 Key Terms ▾
<form>
Container for all input elements. Collects and sends data to a server or script.
<input>
Self-closing tag for user input. The type attribute controls what kind of input appears.
type attribute
Defines input style: text, email, password, checkbox, radio, date, file, etc.
<label>
Descriptive text tied to an input via matching for/id attributes.
<textarea>
Multi-line text input for longer messages or comments.
<select>
Dropdown menu. Each option is wrapped in <option> tags inside.
placeholder
Ghost text shown inside an empty input as a hint to the user.
required
HTML attribute that prevents form submission if the field is empty.
Contact Form Blueprint 
<form action="/submit" method="post">

  <label for="name">Your Name</label>
  <input type="text" id="name"
         placeholder="Nova Builder" required>

  <label for="email">Email</label>
  <input type="email" id="email"
         placeholder="you@example.com" required>

  <label for="msg">Message</label>
  <textarea id="msg" rows="4"></textarea>

  <button type="submit">Send It!</button>

</form>
