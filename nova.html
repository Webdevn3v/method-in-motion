Blueprint Thinking

Before a builder picks up a single brick, they look at the blueprint. HTML is the blueprint of every website you have ever visited. It tells the browser what is on the page and where it belongs.

Think about your bedroom. It has a door, windows, a bed, a desk. Each thing has a purpose and a place. A webpage is exactly the same. It has a header, a main area, a footer, images, text, and links. HTML is how you describe all of those pieces.

The Three Layers of a Website

  • HTML — the structure. The walls, floor, and ceiling of your digital room.
  • CSS — the style. The paint color, furniture, and decorations.
  • JavaScript — the behavior. The lights that switch on, the door that opens.

Nova's world is all about HTML. Master the structure first, and everything else snaps into place.

How the Browser Reads Your Code

When you visit a website, your browser downloads an HTML file and reads it top to bottom, left to right, just like you would read a book. Every instruction you write is followed in order. That predictability is your superpower as a builder.

Your first HTML file
<!DOCTYPE html>
<html>
  <head>
    <title>My First Page</title>
  </head>
  <body>
    <h1>Hello, World!</h1>
    <p>I built this myself.</p>
  </body>
</html>

Key Terms

Lesson 1 Vocabulary▾
HTML
HyperText Markup Language. The language used to build the structure of web pages.
Element
A single piece of HTML, like a heading, paragraph, or image. Made up of tags and content.
Tag
The label that wraps an element. Opening tag: <h1>. Closing tag: </h1>.
Browser
The program (Chrome, Safari, Firefox) that reads HTML and displays it as a visual page.
<head>
The hidden part of the page. Holds the title and settings the browser needs but users don't see.
<body>
Everything inside <body> is what the visitor actually sees on the page.

Building Blocks

HTML gives you a set of building blocks. Each one does one job. Stack them together and you can build anything.

Text Elements

Headings go from <h1> (biggest, most important) to <h6> (smallest). Use them to organize your content like chapters in a book.

Paragraphs use <p>. Every block of body text lives inside one.

Text elements
<h1>Main Title</h1>
<h2>Section Title</h2>
<p>A paragraph of text goes here.</p>

Images and Links

Images use the <img> tag. It is self-closing (no closing tag needed) and uses attributes to know what to show.

Links use <a href="..."> to wrap text or images. The href is where clicking takes you.

Images and links
<img src="nova.png" alt="Nova the Builder">
<a href="https://google.com">Search the Web</a>

Lists

Use <ul> for bullet lists and <ol> for numbered lists. Each item is wrapped in <li>.

Key Terms

Lesson 2 Vocabulary▾
<h1> - <h6>
Heading tags. h1 is the main title. h6 is the smallest sub-heading.
<p>
Paragraph tag. Wraps a block of body text.
<img>
Image tag. Self-closing. Uses src= to link to the image file and alt= to describe it.
<a>
Anchor tag. Creates a link. Uses href= to set the destination.
Attribute
Extra info added inside a tag. Like src="photo.jpg" or href="page.html".
<ul> / <ol>
Unordered list (bullets) and ordered list (numbers). Each item uses <li>.

Layout & Nesting

Individual building blocks are just the start. Real pages are built by grouping elements into sections and nesting them inside containers.

The <div> Tag

A <div> is a box. It holds other elements together so you can move them, style them, and organize them as a group. Think of it like putting furniture into a room.

Using divs to group content
<div class="header">
  <h1>Nova's Page</h1>
  <p>Builder Bot</p>
</div>

<div class="content">
  <p>Main page content here.</p>
</div>

Semantic Tags

HTML5 gives you tags that describe their purpose: <header>, <main>, <footer>, <section>, <nav>. Use these instead of plain divs where you can. They make your code readable and help screen readers.

Nesting Rules

Elements inside other elements are called children. The outer element is the parent. Children must close before their parent closes. This rule keeps your code valid and prevents visual bugs.

Key Terms

Lesson 3 Vocabulary▾
<div>
A generic container. Groups elements so they can be styled and positioned together.
Nesting
Placing elements inside other elements. The inner element is the child; the outer is the parent.
<header>
Semantic tag for the top section of a page or component. Usually holds nav and logo.
<main>
The primary content area of the page. Only one per page.
<footer>
The bottom of a page. Typically holds copyright, links, and contact info.
class=
Attribute that labels an element so CSS can style it. Multiple elements can share a class.
