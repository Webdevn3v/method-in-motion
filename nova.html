Blueprint Thinking

"Before a builder picks up a single tool, they study the blueprint. HTML is that blueprint."

Every website you have ever used was built on the same foundation: HTML. Not magic. Structure. Once you learn to read it, you will never look at a webpage the same way again.

01

HTML is the Structure

HTML tells the browser what is on a page and where it belongs. The heading, the image, the paragraph, the button. HTML describes each one.

02

CSS is the Style

Colors, fonts, spacing, layout. That is all CSS. Nova teaches HTML first because nothing in CSS works without structure underneath it.

03

JavaScript is the Behavior

Clicks, animations, live data. JavaScript makes pages respond. But it needs HTML elements to interact with. Structure always comes first.

04

The Browser Reads Top to Bottom

When you open a site, the browser downloads your HTML file and reads every line in order. Your instructions are followed exactly. That predictability is your power.

A complete HTML page
<!DOCTYPE html>
<html>
<head>
  <title>My First Page</title>
</head>
<body>
  <h1>Hello, World!</h1>
  <p>I built this myself.</p>
</body>
</html>

This is a real, working HTML page. By the end of Lesson 1 you will understand every single line of it.

Key Terms

HTML
HyperText Markup Language. The code language used to build the structure of every webpage.
Element
A single HTML component. Every visible thing on a page is an element.
Tag
The code that marks where an element starts and ends. <h1> opens it. </h1> closes it.
Browser
Chrome, Safari, Firefox. The program that reads HTML and turns it into the page visitors see.
<head>
Invisible section. Holds your page title and setup info the browser uses but visitors never see.
<body>
Everything inside <body> is what visitors actually see and interact with on screen.
Structure
The organization of a page. What comes first, how things are grouped, how they relate.
DOM
Document Object Model. The tree structure a browser builds from HTML so JavaScript can interact with it.

Building Blocks

"Every structure is made of components. Learn each block. Then stack them into something real."
01

Headings — <h1> to <h6>

h1 is your main page title. h2 through h6 create sub-levels. Use them in order like chapters in a book. One h1 per page.

02

Paragraphs — <p>

Every block of body text lives in a <p> tag. Never leave text floating without wrapping it. The browser needs to know what it is.

03

Images — <img>

Self-closing. No closing tag. Needs src= to find the file and alt= to describe it. The alt text is read by screen readers and shown when the image fails to load.

04

Links — <a>

The anchor tag. href= sets where clicking takes you. Wrap text or images inside to make them clickable.

05

Lists — <ul> and <ol>

<ul> gives bullets. <ol> gives numbers. Each item inside uses <li>. Lists power nav menus, feature lists, step instructions.

All five blocks in one page
<h1>My Page</h1>
<p>Welcome to my site.</p>
<img src="me.png" alt="A photo of me">
<a href="about.html">About Me</a>
<ul>
  <li>Coding</li>
  <li>Art</li>
</ul>

Key Terms

<h1> to <h6>
Heading tags. h1 is most important. Never skip levels — always go in order.
<p>
Paragraph tag. Wraps any block of body text. Do not leave text without a tag.
<img>
Self-closing image tag. Needs src= and alt= to work correctly.
<a>
Anchor tag. Creates a link. href= sets the destination.
src=
Source attribute. Points to the image file location on img tags.
href=
HyperReference. Sets the link destination on anchor tags.
alt=
Alternative text. Describes images for screen readers. Required.
<ul> / <ol> / <li>
Unordered (bullets), ordered (numbers), list item. Always nest li inside ul or ol.
Attribute
Extra information inside a tag. Written as name="value". Like src="photo.jpg".
Self-closing Tag
A tag with no closing partner because it holds no content. <img> and <br> are self-closing.

Layout & Nesting

"Individual bricks do not make a building. Group them. Stack them. Organize them. That is layout."
01

The <div> — Your Container

A <div> is a generic box. No visual style on its own. You use it to group elements so CSS can move and style them together as a unit.

02

Nesting — Elements Inside Elements

When you place an element inside another, the outer is the parent and the inner is the child. Children must close before their parent closes. Breaking this rule causes invisible bugs.

03

Semantic Tags — Meaning Built In

<header>, <nav>, <main>, <section>, <footer> — these describe their purpose. Use them instead of <div> when the role is clear. Search engines and screen readers depend on it.

04

The Box Model

Every HTML element is a box with four layers: content, padding (inside space), border, and margin (outside space). This model is the foundation of all CSS layout.

A full semantic page skeleton
<header>
  <nav><a href="/">Home</a></nav>
</header>
<main>
  <section>
    <h1>Welcome</h1>
    <p>Main content here.</p>
  </section>
</main>
<footer>Built with MiM</footer>

Key Terms

<div>
Generic container. Groups elements for styling. No visual appearance on its own.
Nesting
Placing elements inside other elements. Inner = child. Outer = parent.
<header>
Top section of page. Holds logo, nav, and page title.
<nav>
Navigation container. Holds links for moving around the site.
<main>
Primary content of the page. Only one per page.
<section>
A thematic content group. Used for major page areas like About, Projects, Contact.
<footer>
Bottom of the page. Holds copyright, links, contact info.
class=
Gives an element a reusable label. CSS uses class names to apply styles.
Parent / Child
The outer element is the parent. The inner element is the child. CSS can cascade from parent to child.
Box Model
Every element is a box: content + padding + border + margin. The foundation of CSS layout.
