Building Blocks
LESSON 02 · SPARKS+
01 / 05

Headings — <h1> to <h6>

h1 is your main page title. h2 through h6 create sub-levels. One h1 per page.

02 / 05

Paragraphs — <p>

Every block of body text lives in a <p> tag.

03 / 05

Images — <img>

Self-closing. Needs src= to find the file and alt= to describe it.

04 / 05

Links — <a>

The anchor tag. href= sets where clicking takes you.

05 / 05

Lists — <ul> and <ol>

<ul> gives bullets, <ol> gives numbers. Each item uses <li>.

Key Terms
LESSON 02 · TAP TO EXPAND
<h1>-<h6> ›
Heading tags. h1 is most important, never skip levels.
<img> ›
Self-closing image tag. Needs src= and alt=.
<a> ›
Anchor tag. Creates a link. href= sets the destination.
Attribute ›
Extra info inside a tag, written as name="value".

Layout & Nesting
LESSON 03 · CODERS
01 / 04

The <div> — Your Container

A generic box with no visual style on its own. Groups elements so CSS can move and style them together.

02 / 04

Nesting

When you place an element inside another, the outer is the parent and the inner is the child.

03 / 04

Semantic Tags

<header>, <nav>, <main>, <section>, <footer> describe their purpose — use them instead of <div> when the role is clear.

04 / 04

The Box Model

Every element is a box: content, padding, border, and margin.

<header>  <nav><a href="/" >Home</a></nav> </header> <main><section><h1>Welcome</h1></section></main> <footer>Built with MiM</footer>
Key Terms
LESSON 03 · TAP TO EXPAND
<div> ›
Generic container. No visual appearance on its own.
Nesting ›
Placing elements inside other elements. Inner = child, outer = parent.
<main> ›
Primary content of the page. Only one per page.
Box Model ›
Every element is content + padding + border + margin.
