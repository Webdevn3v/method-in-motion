Blueprint Thinking
LESSON 01 · CODERS · SEE THE SKELETON
01 / 09

Every Page Starts With a Skeleton

Think of a website like a house. HTML is the frame and skeleton: walls, rooms, doors, and where everything belongs. CSS is the paint, furniture, and clothes: how the structure looks. JavaScript is the switches, doors, and moving parts: what happens when someone clicks, types, or interacts. Nova starts with HTML because a strong build begins with structure.

02 / 09

HTML = Structure

HTML stands for HyperText Markup Language. It labels the pieces of a page so the browser knows, “This is a heading. This is a paragraph. This is a link.” HTML answers: What is here, and how is it organized?

03 / 09

Tag Anatomy — OPEN → CONTENT → CLOSE

Before we inspect a whole document, learn to read one element:

<h1>Hello</h1>

< begins a tag. h1 is the tag name. > ends the opening tag. Hello is the content. </h1> closes the element, and the / marks a closing tag. Memory rule: OPEN → CONTENT → CLOSE.

04 / 09

Tag vs Element

A tag is one markup marker, such as <p> or </p>. An element is the complete piece: opening tag + content + closing tag, such as <p>Hello</p>. Tags are the labels; the full labeled block is the element.

05 / 09

Layer 1 — Tell the Browser What Kind of Document This Is

<!DOCTYPE html>

<!DOCTYPE html> goes first. It tells the browser to use modern HTML rules. It is a declaration, not a normal paired element, so it does not need a closing tag.

06 / 09

Layer 2 — The HTML Wrapper

<html> ... </html>

The <html> element wraps the HTML document. Everything else in the page skeleton belongs inside it.

07 / 09

Layer 3 — Head and Body

<html> <head> <title>My First Page</title> </head> <body> <h1>Hello, World!</h1> </body> </html>

<head> holds setup information. <title> appears in the browser tab, not as visible page text. <body> holds what visitors actually see.

html ├── head │ └── title └── body └── h1
08 / 09

The Browser Reads Top to Bottom — and Inside to Outside

The browser reads the file in order, but it also notices which elements are inside other elements. That relationship is called nesting. You will investigate it deeply in Lesson 3.

09 / 09

Indentation Is Your X-Ray Vision

Indentation usually does not change how HTML behaves, but it makes structure easier for humans to see. When an element lives inside another element, move it inward. Each indent is a clue showing the page's parent/child structure.

Nova memory map: SKELETON → SECTIONS → BLOCKS → NEST → BUILD.

Building Blocks
LESSON 02 · CODERS · IDENTIFY THE BLOCKS
01 / 10

Headings Build a Hierarchy

<h1>My Animal Site</h1> <h2>Dogs</h2> <h3>Golden Retrievers</h3>

Heading numbers show importance and hierarchy, not just size. h1 is the main page topic, h2 is a major section, and h3 is a subsection. Keep levels logical instead of jumping randomly from h1 to h4. Each heading still follows OPEN → CONTENT → CLOSE.

02 / 10

Paragraphs Hold Supporting Text

<p>I love learning how websites are built.</p>

A heading labels a topic. A paragraph explains or supports it. <p> opens the paragraph, the sentence is content, and </p> closes it.

03 / 10

Attributes Add Extra Information

An attribute is extra information written inside an opening tag. The pattern is name="value". The = connects the attribute name to its value, and quotes wrap the value.

<tag name="value">
04 / 10

Images — A Void Element

<img src="nova.png" alt="Nova exploring a holographic map">

img creates an image. src tells the browser where the file lives. alt describes the image for accessibility or when the image cannot load. <img> is a void element: it does not wrap content and does not need </img>. A filename like "photo.jpg" can point to a file in the same folder; a full URL can point elsewhere.

05 / 10

Links — Destination + Clickable Content

<a href="about.html">About Me</a> <a href="https://example.com">Visit Example</a>

a means anchor. href is the destination. The words between the tags are what the visitor clicks. A destination such as #about can jump to a section inside the same page — you will connect that in Lesson 4.

06 / 10

Lists Are Containers With Items Inside

<ul> <li>Coding</li> <li>Skating</li> </ul>

ul makes an unordered/bulleted list. ol makes an ordered/numbered list. Each li is one list item and belongs inside its list container. You are already seeing parent/child nesting.

07 / 10

Paired vs Void Elements

Paired elements wrap content: <p>...</p>, <h1>...</h1>, <a>...</a>. A void element such as <img> does not wrap content and has no closing tag. If you see </img>, that is a clue something is wrong.

08 / 10

Attribute Detective: src, href, alt

Use src to tell an image where its file is. Use href to tell a link where to go. Use alt to describe an image. Different elements expect different attributes.

09 / 10

Discovery Errors — Spot the Glitch

Common beginner clues: a paired tag never closes; quotes are missing around an attribute value; a link uses src instead of href; an image has no useful alt; an li sits outside its ul/ol; or heading levels jump randomly.

10 / 10

Block Check

When you read a line of HTML, ask: What element is this? Does it open and close? Does it have attributes? What content or child elements belong inside? That is how Nova reads a page X-ray.

Key Terms
LESSON 02 · TAP TO EXPAND
<h1>-<h6> ›
Heading tags. h1 is most important, never skip levels.
<img> ›
Self-closing image tag. Needs src= and alt=.
<a> ›
Anchor tag. Creates a link. href= sets the destination.
Attribute ›
Extra info inside a tag, written as name="value".

Layout & Nesting
LESSON 03 · CODERS · NEST THE BLOCKS
01 / 09

<div> — A Generic Container

A <div> groups related content when no more meaningful HTML element fits.

<div> <h2>About Me</h2> <p>I build things.</p> </div>

Grouping creates structure first. CSS can style that group later.

02 / 09

Nesting = Boxes Inside Boxes

Imagine rooms inside a house or boxes inside bigger boxes. When one HTML element sits inside another, it is nested.

<section> <h2>About</h2> <p>Hello!</p> </section>

section is the parent. h2 and p are its children. Because those two children share the same parent, they are siblings.

03 / 09

Closing Order — Last Opened, First Closed

Nested elements close in reverse order. Memory rule: Last opened, first closed.

✓ CORRECT <section> <p>Hello</p> </section> ✗ BROKEN <section> <p>Hello </section> </p>
04 / 09

Indentation Shows Relationships

Move child elements inward. Indentation is a visual map for humans: elements lined up at the same level are often siblings; elements shifted inward are nested children.

05 / 09

Semantic Tags Tell You Their Job

Semantic means the tag name describes what the content is for. <header> = introductory/top content. <nav> = navigation links. <main> = primary unique page content. <section> = a grouped topic. <footer> = ending/site information. A page normally has one primary <main>.

06 / 09

Div or Semantic Tag?

If a meaningful semantic tag fits the job, use it. If you only need a generic group with no specific meaning, use <div>.

Meaningful page section <section>...</section> Generic grouping box <div>...</div>
07 / 09

Semantic Skeleton X-Ray

body ├── header │ └── nav ├── main │ └── section └── footer

This is the same idea as Skeleton Stack: identify the large page regions first, then inspect which blocks live inside each region.

08 / 09

CSS Preview — The Box Model

Every element can be imagined as a box: content is what is inside, padding is space inside the border, border is the edge, and margin is space outside. This is only a preview — Nova's priority is getting the HTML structure right before styling it.

09 / 09

Nesting Check

Ask: Who is the parent? Who are the children? Which elements are siblings? Did the last element opened close first? Can indentation make the structure easier to see?

Key Terms
LESSON 03 · TAP TO EXPAND

Nesting ›

<main> ›

Box Model ›
Every element is content + padding + border + margin.

▲ Your Personal Site — A MiM Journey Project

What you build here is the foundation of a real personal website that every MiM character will help you grow. Nova gives you the HTML skeleton today.

Nova — HTML Structure (You are here)+ CSS Styling (coming soon)+ JavaScript (coming soon)+ Final Launch (coming soon)
01 / 08

Recap — What You Already Know

You can now read the document skeleton, use OPEN → CONTENT → CLOSE, recognize attributes, add headings/paragraphs/links/images/lists, and nest blocks into semantic sections. Now combine those discoveries into one page.

02 / 08

Stage 1 — Document Skeleton

<!DOCTYPE html> <html> <head> <title>My Site</title> </head> <body> </body> </html>

DOCTYPE declares modern HTML. HTML wraps the document. Head holds setup information. Title names the browser tab. Body holds visible page content.

03 / 08

Stage 2 — Header + Navigation

<header> <h1>Your Name</h1> <nav> <a href="#about">About</a> </nav> </header>

href="#about" means “jump to the element whose id is about.” The # points to an ID on this page.

04 / 08

Stage 3 — Main + Hero Section

<main> <section> <h2>Welcome</h2> <p>I am learning to build the web.</p> </section> </main>

main holds the page's primary unique content. The section is a child of main, and its heading and paragraph are children of the section.

05 / 08

Stage 4 — Connect a Hash Link to an ID

<a href="#about">About</a> <section id="about"> <h2>About Me</h2> </section>

id is an attribute that gives one element a unique name. The link's #about target matches id="about". Change one without changing the other and the jump link breaks.

06 / 08

Stage 5 — Footer

</main> <footer> <p>Built by me.</p> </footer> </body>

The footer sits outside main because it is ending/site information, but it remains inside body because it is visible page content.

07 / 08

Stage 6 — Validate Before Launch

Run Nova's X-ray checklist: Are all paired tags closed? Does nesting close in reverse order? Is visible content inside body? Is title inside head? Do images have useful alt text? Do nav links point to real IDs or pages? Fix structure before styling.

08 / 08

What the Builder Is Actually Generating

The fields below are not magic boxes. Your site name becomes an h1. Navigation becomes a elements. Your sections become semantic HTML inside main. When you download the file, you are saving the same skeleton you learned to read — now filled with your own content.

▲ Common HTML Bugs — X-Ray Debug Box

Missing close
Check every paired element has its matching closing tag.
Wrong nesting
Close in reverse order: last opened, first closed.
Attributes
Check quotes, href vs src, useful alt text, and unique IDs.
Lists
li belongs inside ul or ol.
Head/body
Visible content belongs in body; title/setup belongs in head.
Hash links
href="#name" needs a matching id="name".
