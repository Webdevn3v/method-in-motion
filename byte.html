Data Basics
LESSON 01 · CODERS
01 / 04

What Is Data?

Data is any piece of information a computer stores or works with — a name, a score, an answer of yes or no, a whole list of favorite songs. Every app you've ever used is built on data moving around behind the scenes.

02 / 04

The Basic Data Types

Code sorts data into types. A string is text in quotes, like "Byte". A number is a numeric value, like 7. A boolean is only ever true or false. Every piece of data you'll ever track fits into one of these.

03 / 04

Storing Data in a Variable

A variable is a labeled container that holds a piece of data so code can use it later.

let name = "Byte"; let score = 100; let isReady = true;
04 / 04

Why Type Matters

Knowing a value's type tells you what you can do with it. You can add two numbers together, but you can't add two words the same way. Byte always checks the type first.

05 / EXPANSION

See It: Classify Before You Code

Byte finds the type before touching the code. "Nova" is a string, 27 is a number, and false is a boolean. Quotes signal text, digits without quotes signal a number, and true/false signal a boolean.

06 / EXPANSION

Break It Apart: Label → Container → Value

Read let score = 100; in three parts: score is the label, the variable is the container created with let, and 100 is the value. Byte's method: identify the type → find the pattern → organize it clearly.

Patterns & Sequences
LESSON 02 · CODERS
01 / 04

Data Rarely Travels Alone

Most real data comes as a group — a playlist, a class roster, a list of high scores. In code, an ordered group of values is called an array.

let songs = ["Track A", "Track B", "Track C"];
02 / 04

Every Item Has a Position

Each value in an array has an index — its position in line, starting at 0, not 1. The first item is index 0.

03 / 04

Spotting a Pattern

A pattern is a sequence that repeats or follows a rule — every other item is a number, every third item is red. Byte's whole job is noticing patterns like this in data.

04 / 04

Reading an Array by Index

Use square brackets and the index number to pull out one item.

songs[0]; // "Track A" — the first item
05 / EXPANSION

Predict the Position

For ["pink", "cyan", "gold"]: pink = 0, cyan = 1, gold = 2. Arrays count from zero. Repeat it: first item, index 0.

06 / EXPANSION

Pattern → Array Connection

If the sequence is 2, 4, 6, 8, the rule is “add 2.” Arrays preserve order, so Byte checks the order, finds the rule, then uses an index to retrieve the clue.

Key Terms
LESSON 02 · TAP TO EXPAND
Array ›
An ordered list of values stored in one variable.
Index ›
The position of an item in an array, starting at 0.
Sequence ›
A set of values in a specific order.
Pattern ›
A sequence that repeats or follows a predictable rule.

Organizing Information
LESSON 03 · CODERS
01 / 04

When a List Isn't Enough

An array is great for a simple list, but real information is often more organized than that — it has labeled parts. That's what an object is for.

02 / 04

Key-Value Pairs

An object stores data as key-value pairs — a label (key) connected to a piece of data (value).

let character = {
  name: "Byte",
  role: "Data Tracker",
  level: 4
};
03 / 04

Reading a Property

Use a dot to reach into an object and grab one piece of it.

character.name; // "Byte"
04 / 04

Grouping and Sorting

Organizing data often means grouping similar items together or sorting them into an order — smallest to largest, A to Z. Byte always organizes before drawing conclusions.

05 / EXPANSION

Match the Key to the Value

In { name: "Byte", level: 4 }, name matches "Byte" and level matches 4. The key is the label; the value is the information attached to it.

06 / EXPANSION

Loose Data vs. Organized Data

"Byte", "Data Tracker", 4 has values but no labels. { name: "Byte", role: "Data Tracker", level: 4 } organizes the same clues so each one is easy to retrieve.

Key Terms
LESSON 03 · TAP TO EXPAND
Object ›
A collection of labeled data stored as key-value pairs.
Key ›
The label attached to a value inside an object.
Value ›
The actual piece of data connected to a key.
Sort ›
To arrange data into an order, like smallest to largest.
Group ›
To collect similar pieces of data together.
